# Support

## Getting Help

- Usage questions: open a GitHub Discussion or Issue.
- Bug reports: use the bug report issue template.
- Security issues: follow `SECURITY.md` and use private reporting.

## Before Opening a Request

- Read `README.md` for setup and troubleshooting.
- Check `docs/ARCHITECTURE.md` for technical behavior and data flow.
- Search existing issues to avoid duplicates.

## Response Time

Maintainer response times are best-effort and may vary.
